# 설계 기록 (ADR)

방향을 크게 바꾼 결정만 남긴다. **무엇을 정했는지보다 왜 그렇게 정했는지**가
핵심이다 — 나중에 같은 갈림길을 다시 만났을 때 처음부터 따져보지 않으려고
쓴다. 뒤집는 것도 괜찮다. 뒤집을 때는 지우지 말고 새 기록을 더하고 옛것에
`대체됨`을 적는다.

일상적인 구현 요령은 여기 오지 않는다. 그건 코드 옆이 제자리다 —
추출기 휴리스틱은 [`tools/pdfextract/README.md`](../tools/pdfextract/README.md)의
'구현 메모'에 있다.
