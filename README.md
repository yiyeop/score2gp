# Score2GP

_한국어 · [English](README.en.md)_

**PDF 악보를 소리로.** 악보 프로그램이 내보낸 PDF를 읽어 TAB·리듬·주법까지
Guitar Pro 파일로 옮깁니다. 재생 위치를 악보에 짚어 주고 속도를 늦출 수 있어,
그대로 따라 연습할 수 있습니다.

읽을 수 있는 건 **벡터 PDF** — Guitar Pro·Finale·MuseScore에서 "PDF로 내보내기"한
파일입니다. 스캔본이나 사진은 지원하지 않습니다.

## 할 수 있는 일

- **악보 열기** — `.gp`, `.gp3`~`.gpx`, MusicXML. 파일이 없으면 내장 데모 곡으로 바로 체험할 수 있습니다
- **따라 연습** — 재생 위치가 악보 위를 따라가고, 속도를 25~200%로 늦추거나
  구간을 반복할 수 있습니다. 메트로놈과 카운트인도 있습니다
- **파트 고르기** — 트랙별로 악보에 표시할지, 소리를 낼지(볼륨·뮤트·솔로)를 따로 정합니다
- **구간 타임라인** — 곡 전체를 한 줄로 보여 줍니다. Intro·Verse·Chorus 같은 구간과
  톤 변화를 눌러 그 마디로 바로 갑니다
- **주법 설명** — 음에 마우스를 올리면 슬라이드·태핑·피킹 하모닉스 같은 주법을
  초보자용 설명으로 알려줍니다
- **PDF 변환** — 악보 PDF를 넣으면 연주할 수 있는 Guitar Pro 파일로 바꿉니다.
  변환기가 앱 안에 함께 들어 있어 파이썬을 따로 깔 필요가 없습니다
- **편집 모드** — 변환이 잘못 읽은 음을 프렛·줄·길이 단위로 고치고, 마디별 톤도 넣을 수 있습니다
- **내보내기** — Guitar Pro 7(`.gp`)·MIDI·alphaTex로 저장합니다
- **한글 제목 복구** — 구형 Guitar Pro 파일의 깨진 한글(CP949)을 자동으로 되살립니다
- 단축키는 앱에서 `?` 키로 볼 수 있습니다

## 설치

### [⬇ 최신 버전 받기](https://github.com/yiyeop/score2gp/releases/latest)

| 운영체제              | 받을 파일                         |
| --------------------- | --------------------------------- |
| macOS (Apple Silicon) | `.dmg`                            |
| Windows               | `-setup.exe` (또는 `.msi`)        |
| Linux                 | `.AppImage` (또는 `.deb`, `.rpm`) |

운영체제마다 골라야 할 파일은 확장자로 하나씩 정해진다. 파일 이름에 붙는
아키텍처 표기(`x64` `aarch64` 등)는 빌드 도구가 정하는 것이라 여기 적지
않는다 — 적어 두면 도구가 표기를 바꿀 때 안내만 조용히 틀려진다.

> **macOS는 Apple Silicon(M1 이상) 전용이다.** Intel Mac에서는 Rosetta로도
> 실행되지 않는다. 애플 메뉴 → 이 Mac에 관하여 → 칩이 `Apple M…`인지 확인하면 된다.

### 처음 열 때 경고가 뜬다

서명하지 않은 빌드라 운영체제가 막아선다. 한 번만 허용하면 그다음부터는 그냥 열린다.

**macOS**

1. 받은 `.dmg`를 열고 `score2gp`를 `Applications` 폴더로 끌어다 놓는다
2. 앱을 실행하면 "열 수 없습니다"가 뜬다 — 일단 닫는다
3. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래로 내려가면
   `score2gp`이(가) 차단되었다는 줄이 있다. **그래도 열기**를 누른다
4. 다시 실행하고 **열기**를 누른다

터미널이 편하면 한 줄로도 된다.

```bash
xattr -dr com.apple.quarantine /Applications/score2gp.app
```

**v0.1.2 이하에서 "손상되었기 때문에 열 수 없습니다"가 뜨면** — 그 버전들은
번들 서명이 깨진 채 배포돼서 **그래도 열기**가 나오지 않는다. 휴지통으로
옮기지 말고 창을 닫은 뒤 위의 터미널 명령을 쓰거나, 새 버전을 받는다.

**Windows**

SmartScreen이 "Windows의 PC 보호"를 띄우면 **추가 정보** → **실행**을 누른다.

## 한계

- **스캔본·사진은 읽지 못한다.** 악보 프로그램이 내보낸 벡터 PDF만 다룬다
  ([왜 그렇게 정했는지](adr/0001-vector-pdf-instead-of-omr.md))
- 변환은 완벽하지 않다. 잘못 읽은 음은 **편집 모드**에서 고칠 수 있다
- 배포본에 서명이 없어 첫 실행에 한 번 막힌다 (위 "처음 열 때 경고" 참고)
